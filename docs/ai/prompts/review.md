# Code Review Prompt

请以阻止生产事故为目标审查本次改动，优先检查：

1. 系统代理是否可能无法恢复。
2. ChatGPT/Codex 检测是否会误选 helper 或资源内可执行文件。
3. Windows AppX 和 macOS Bundle ID 是否处理正确。
4. 是否泄露订阅、代理凭据、Token 或签名私钥。
5. 下载是否验证状态码、长度、取消和部分文件。
6. 异步任务是否阻塞 UI 或遗留子进程。
7. Tauri capability 是否过宽。
8. REST 类型和前端类型是否一致。
9. 测试是否覆盖真实失败路径。

先输出按严重程度排序的问题，再给出简短总结。没有问题时明确说明剩余测试缺口。
