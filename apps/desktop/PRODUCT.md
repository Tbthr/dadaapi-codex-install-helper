# Product

## Platform

adaptive

## Users

主要用户是使用 ChatGPT、Codex 及相关 AI 工具的中文用户，工作环境为 Windows 或 macOS 桌面端。他们需要在不手动编辑复杂配置或网络设置的情况下，把受支持的 AI 桌面应用配置为中文并正常使用。

## Product Purpose

哒哒助手是哒哒 API 品牌下的开源桌面工具。它在用户本机检测受支持的 ChatGPT/Codex 应用，完成中文配置、连接准备、应用重启和中文界面验证，并提供安全的原网络恢复流程；同时提供相关官方软件和 CLI 工具的发现、下载与安装辅助。产品成功意味着用户可以用一条可理解、可恢复的流程完成中文配置，并清楚知道网络何时仍由临时代理承载、何时已经恢复。

## Positioning

哒哒助手的核心机制是本地完成、可验证、可恢复的中文激活：客户端优先从 Gitee、备用从 GitHub Raw 获取签名加密路由包，在本机验签、校验、解密、筛选节点并连接选中的节点；它不要求账户或卡密，也不把 ChatGPT/Codex 代理流量转发到哒哒 API 服务器。

## Operating Context

- 用户先启动 ChatGPT 或旧版 Codex，再打开哒哒助手；客户端检测安装路径、运行状态和现有语言配置。
- 中文流程会在必要时启动临时本地代理、保存原网络状态、写入配置、重启目标应用，并验证 Renderer 是否以 `zh-CN` 运行。
- 中文验证成功后临时代理可以继续运行；用户在界面中手动恢复原网络。恢复失败时保留恢复记录，供用户重试。
- 用户可以从软件页访问哒哒 API 的模型价格、控制台、账户充值、新手指南和 QQ 群，也可以下载官方桌面软件及 Node.js、Codex CLI、Claude Code CLI 等配套工具。

## Capabilities and Constraints

- 支持 Windows 和 macOS，识别新版 ChatGPT、旧版 Codex，并覆盖 Windows 常规安装和 Microsoft Store 路径。
- 中文配置写入前备份原文件，写入失败时恢复现场；支持幂等写入、恢复原语言配置、目标应用重启和中文效果验证。
- 路由配置必须同时具备清单地址、Ed25519 验签公钥、XChaCha20-Poly1305 解密密钥和密钥标识；缺少完整构建配置时客户端保持只读检测能力，不能伪造激活成功。
- 路由下载优先 Gitee、备用 GitHub Raw，必须验签、校验 SHA-256、解密并只缓存允许的密文及签名材料；支持 VLESS TCP/TLS 与 Hysteria2 节点。
- 修改系统代理前必须持久化恢复状态。客户端启动时只提示遗留状态，不自动改写网络配置；中文激活后由用户手动恢复原网络，且必须先恢复原网络配置再关闭本地代理。
- 官方软件安装包通过用户本地网络和官方地址下载，支持真实进度、取消、重试、断点续传、校验和下载完成后的安装包打开；客户端不提供在线自更新。
- 产品不使用卡密、登录、IP 绑定或使用次数验证，不包含 Go 二进制或 Sidecar，不接入软件下载镜像。
- 前端使用简体中文，界面只展示已实现的真实功能和状态；不得把需求说明、开发计划、技术栈或占位模块放入产品页面。

## Product Principles

1. 本地优先：关键配置、验证和网络控制尽可能在用户设备上完成。
2. 先保护再修改：任何系统网络变更都必须先保存可恢复状态。
3. 验证后宣称成功：只有真实完成配置、重启和效果验证，才能向用户报告成功。
4. 来源可验证：官方软件与路由配置必须经过来源、完整性和适用性检查。
5. 降低门槛：不以登录、卡密、IP 绑定或次数限制阻断用户完成任务。
